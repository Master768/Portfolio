## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Master768/Portfolio.git

# Navigate into the project directory
cd Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Typecheck and build optimized static assets into dist/
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Netlify Deployment

The project is pre-configured for one-click deployment on Netlify:
- **Build Command**: `npm run build`
- **Publish Directory**: `dist`
- **SPA Redirects**: Included in `public/_redirects` and `netlify.toml`
- **Forms**: Netlify Forms backend configured for direct contact submissions without third-party email APIs.
